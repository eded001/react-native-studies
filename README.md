# React Native

## Sobre

- Framework de desenvolvimento mobile
- Code-base único
- Multiplataforma

## Sintaxe básica

### Componentes

Basicamente um elemento ou uma peça, ou seja, um pedaço de software que pode ser "encaixado". Então, cada componente é um pedaço de código.

### JSX

Uma extensão do JS que permite a inserção de tags HTML

#### Sintaxe

Os elementos podem ser
- Self opening: `<element></element>`
- Self closing: `<element />`

Os atributos são
- Self opening: `<element attr={attribute} />`

### Props

Argumentos passados em componentes reacts via atributos.

### State

Mantém o controle sob os dados dos componentes.

#### Props x State

Props: Renderiza uma configuração

State: Armazena um estado

### Hooks

Uma ferramenta que permite a adição de funcionalidades através de um link
